# User Guide

Welcome to the POTLAUNCH User Guide! This guide will help you get started with creating tokens, participating in launches, and using all the platform features.

## What You'll Learn

This user guide covers everything you need to know as a POTLAUNCH user:

- **Getting Started** - Set up your wallet and connect to the platform
- **Creating Tokens** - Launch your own token step-by-step
- **Participating in Launches** - Buy and trade tokens on the platform
- **Cross-Chain Features** - Bridge tokens across multiple blockchains
- **Managing Your Tokens** - Track and manage your token launches

Whether you're a token creator or a community member looking to participate in launches, this guide has you covered.

## Prerequisites

Before you start using POTLAUNCH, make sure you have:

1. **A Solana Wallet** - We recommend [Phantom](https://phantom.app/) or [Backpack](https://backpack.app/)
2. **SOL Tokens** - For transaction fees (typically 0.01-0.1 SOL is sufficient)
3. **Optional: Base/NEAR Wallet** - For cross-chain bridging features

## Getting Started

### Step 1: Set Up Your Wallet

**Download Phantom Wallet:**
1. Visit [phantom.app](https://phantom.app/)
2. Install the browser extension or mobile app
3. Create a new wallet and **securely save your recovery phrase**
4. Fund your wallet with SOL

> **⚠️ Security Warning**: Never share your recovery phrase! Store it securely offline. Phantom will never ask for it.

### Step 2: Connect to POTLAUNCH

1. Visit [potlaunch.com](https://potlaunch.com/)
2. Click **"Connect Wallet"** in the top right corner
3. Select your wallet (Phantom, Backpack, etc.)
4. Approve the connection request in your wallet

✅ You're now connected and ready to use POTLAUNCH!

### Step 3: Explore the Platform

Once connected, you can:

**Browse Existing Tokens:**
- Explore trending token launches
- View token details, charts, and bonding curves
- Check community engagement and trading volume
- Buy tokens directly on the platform

**Create Your Own Token:**
- Click **"Launch Token"** to start the creation process
- Follow the guided setup with helpful tooltips
- Customize your token parameters and launch mechanism
- Deploy your token and start building your community!

## Tips for Success

### For Token Creators

✅ **Do:**
- Research similar projects and learn from them
- Engage with your community early and often
- Set realistic tokenomics and goals
- Be transparent about your project
- Test on testnet first

❌ **Don't:**
- Rush the launch without proper planning
- Over-promise on unrealistic features
- Ignore community feedback
- Set exploitative fee structures
- Launch without understanding the mechanics

### For Participants

✅ **Do:**
- Research projects thoroughly before participating
- Start with small amounts to learn the platform
- Understand the risks of early-stage tokens
- Engage with project communities
- Use security best practices with your wallet

❌ **Don't:**
- Invest more than you can afford to lose
- Fall for obvious scams or unrealistic promises
- Share your wallet's recovery phrase with anyone
- Rush into purchases without research
- Ignore red flags or warning signs
